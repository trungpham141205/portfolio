Learning Roadmap

My portfolio is structured as an engineering progression, not just a list of small circuits. Each project should prove one design skill clearly.

Phase 1 — Combinational RTL Foundation

Half Adder, Full Adder, Ripple Carry Adder, Carry Lookahead Adder. Main focus: Boolean logic, datapath composition, propagation delay, and testbench checking.

Phase 2 — Sequential Logic & Timing

SIPO register and timing-aware designs. Main focus: flip-flops, reset behavior, setup/hold thinking, waveform reading, and timing validation.

Phase 3 — FSM Design

Traffic Light Controller. Main focus: state definition, next-state logic, output logic, counter-based timing, and clean RTL partitioning.

Phase 4 — CPU Architecture

RV32I Single-Cycle CPU. Main focus: instruction fetch, decode, ALU control, register file, memory access, and processor datapath integration.

Phase 5 — SoC Direction

SoC-RV32I-CNN and future secure SoC projects. Main focus: memory-mapped architecture, accelerator integration, bus interface thinking, and system-level verification.
